# 09 · 免训练基线：VLM 智能体（Claude Haiku 5.5）+ 逆运动学

[English](09_zero_shot_vlm.md) · **简体中文**

PS：状态：设计和基础模块已就绪；智能体循环、不依赖示范的标定和评估是下一步。

## 1. 为什么要做这组实验

前面四个策略（ACT、Diffusion、SmolVLA、π₀.₅）都**用我们的 50 条示范训练过**：学的是"图像 → 动作"。
另一条路线是**完全不训练**：一个没见过机器人数据的通用视觉语言模型（VLM）看着相机，一步步自己决定怎么做这个任务。
把它放在**同一个任务、同一套评估协议**下比，回答一个很实际的问题：

> 50 条人工示范加上训练，到底比"现成的模型直接做决策"多带来多少？各自在什么情况下失败？

为了比得公平，这个基线不从示范里取任何东西：标定和高度都在现场测量，40 次评估前冻结所有设置。

## 2. 设计

### 2.1 为什么不让模型直接输出关节角

没训练过的模型不知道这台机械臂的运动学。要它直接输出关节角，它只能看一眼、动一点，几十步地挪过去，这就成了长程问题，要很大的模型。
换成笛卡尔接口，同一个任务只要 5–10 个决策（到玩具上方、下降、合上、抬起、移到盒子上方、松开），小而便宜的模型就能胜任。

这里的 IK 相当于驱动（像汽车方向盘把"往左"变成车轮转角），不做任何任务决策。
论文里的免训练系统也是这样搭的（Code as Policies、VoxPoser、MOKA、ReKep、Gemini Robotics-ER）：大模型做决策，下面接一个通用的笛卡尔 / IK 执行层。

| | 谁来决定 |
|---|---|
| 抓哪里、抬多高、怎么走、什么时候松手、要不要重来 | **VLM** |
| 把"夹爪到 (x, y, z)"换算成关节角 | IK（第 3.4 节） |
| 关节限位、限速、不低于桌面 | 安全检查 |

### 2.2 给模型的工具

| 工具 | 作用 |
|---|---|
| `look()` | 返回俯视图、腕部图和夹爪当前位置 (x, y, z) |
| `move_to(x, y, z)` | 把夹爪尖移到那里、朝下（IK + 关节限速 + 路径检查） |
| `gripper(opening)` | 张开（0–100）或合上夹爪 |
| `done(result)` | 结束这次尝试 |

整个过程是闭环的：每动一次模型都重新看一眼，所以抓空了、玩具滑了，它都能纠正。

### 2.3 模型和费用

通过 Anthropic API 调用 Claude Haiku 5.5：能看图、能调用工具；输入 / 输出每百万 token $0.10 / $0.50。
每次尝试约十次调用，40 次加起来远不到 1 美元。账号和密钥由用户自己设置（`ant auth login` 或 `ANTHROPIC_API_KEY`），不写进仓库。

## 3. 基础模块

模型用桌面坐标（机械臂底座坐标系里的厘米）来思考，所以需要一个像素 → 桌面的映射；`move_to` 需要正运动学和逆运动学。

### 3.1 从像素到桌面：单应性矩阵（homography）

相机拍到的是 2D 画面，机械臂要的是 3D 坐标。一般来说这需要深度，但我们的情况特殊：**玩具和盒子都在桌面上**，桌面是一个平面。
而一个平面经过透视投影到另一个平面（图像），这个映射正好是一个 3×3 矩阵 $H$，在齐次坐标下：

$$\begin{bmatrix} x \\ y \\ 1 \end{bmatrix} \sim H \begin{bmatrix} u \\ v \\ 1 \end{bmatrix},\qquad x = \frac{h_{11}u + h_{12}v + h_{13}}{h_{31}u + h_{32}v + h_{33}},\quad y = \frac{h_{21}u + h_{22}v + h_{23}}{h_{31}u + h_{32}v + h_{33}}$$

$H$ 只差一个整体缩放，所以有 8 个自由度。每对"像素 ↔ 桌面点"给 2 个方程，**4 对点就能解出来**，更多的点用最小二乘。
分母里的 $h_{31}, h_{32}$ 就是透视效果（近大远小）。所以**不需要深度相机**，也不需要知道相机内参。

### 3.2 不用示范的标定

求 $H$ 的办法：用夹爪尖去碰桌面上分散的 6–8 个点（遥操作，或者关掉扭矩用手掰），用正运动学（第 3.3 节）读出夹爪尖的位置，
同时在俯视图上标出这几个点。这是标准的相机-机械臂标定，每套装置做一次，不涉及任何任务示范。
模型需要的高度（盒壁、玩具）用尺子量。

### 3.3 正运动学（FK）

机械臂是一串"连杆 + 关节"。URDF 文件里写了每个关节相对上一个连杆的固定偏移（平移 + 旋转）和转轴。
所以夹爪尖在底座坐标系里的位姿就是一串 4×4 齐次变换相乘：

$$T_{\text{tip}}(q) = \prod_{i=1}^{5} \Big( T_i^{\text{fixed}} \cdot \mathrm{Rot}(\text{axis}_i,\ q_i) \Big) \cdot T^{\text{tip}}$$

$T$ 的左上 3×3 是朝向，右上 3×1 是位置。

PS：LeRobot 0.7 里 SO-101 的关节读数就是"度"，0° = 标定范围的中点，和官方 `so101_new_calib.urdf` 的零点一致，所以可以直接代进去。
我们用示范验证过：35 次桌面抓取时，FK 算出的夹爪尖高度是 **−0.8 ± 1.0 cm**（夹爪尖略压进软桌垫），抓取位置聚成 5 簇，正好对应 5 个胶带标记点。
零点或者方向错了的话，这些数会乱掉。

### 3.4 逆运动学（IK）：阻尼最小二乘

IK 是反过来：给定目标"夹爪尖在 $p^*$、夹爪朝下"，求关节角 $q$。SO-101 只有 5 个关节（其中 wrist_roll 只让夹爪绕自身转，不影响位置），
所以没法任意指定姿态，但"位置 + 朝下"这个约束是解得出来的。

没有闭式解，所以用迭代。定义残差（6 维）：

$$r(q) = \begin{bmatrix} p(q) - p^* \\ w \cdot \big(z_{\text{approach}}(q) - [0, 0, -1]^T\big) \end{bmatrix}$$

前 3 维是位置误差，后 3 维是"夹爪接近方向"和"竖直向下"的差，$w = 0.05$ 是权重。每一步用数值雅可比 $J = \partial r / \partial q$（每个关节动 0.01° 看残差变多少），然后

$$\Delta q = -J^T \big(J J^T + \lambda^2 I\big)^{-1} r$$

- 没有 $\lambda$ 的话这就是高斯-牛顿法；但机械臂接近奇异姿态（比如手臂伸直）时 $JJ^T$ 接近不可逆，$\Delta q$ 会爆掉。
  加上 $\lambda^2 I$ 之后，步长在奇异点附近会自动变小。这就是**阻尼最小二乘**（Levenberg-Marquardt 的思路）。
- PS：$\lambda$ 的大小要和单位匹配：关节动 1° 夹爪尖只移动约 3 mm，雅可比的元素在 $10^{-3}$ 量级，所以 $\lambda \approx 10^{-3}$。
- 每一步结束后把关节角裁到 URDF 的限位里。
- 初值很重要：从收拢的起始姿态出发，shoulder_lift 正好卡在 −100° 的限位上，会卡住。所以用示范里几种典型的抓取姿态做初值，取误差最小的那个。（现在这些初值取自示范里的典型抓取姿态；这个基线会把它们换成在关节范围内均匀分布的初值，不从示范里取任何东西。）

结果：桌面目标误差 **0.1 mm**，夹爪竖直向下。
